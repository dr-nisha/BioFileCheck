# Application preparation

## Project name
BioFileCheck — Bioinformatics Sequence File Validation Toolkit

## Project description
I am developing an early-stage Python toolkit that checks DNA FASTA and FASTQ files before downstream bioinformatics analysis. The current prototype detects structural and sequence-alphabet errors and produces reproducible JSON reports. The repository includes synthetic examples and automated tests. Planned development includes paired-end consistency checks, explicit quality summaries, and a local HTML report.

## Why AI-assisted development fits
The project offers concrete tasks in parser design, edge-case handling, testing, performance and reporting. I can evaluate proposed code using reproducible tests and domain-specific reasoning about sequence formats and scientific assumptions.
